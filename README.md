# 숨길 · Soomgil

국내 여행지를 **취향과 지역으로 찾아보고, 다녀온 경험을 기록하는** 웹앱입니다. 기존 기획과 공개 장소 데이터를 바탕으로 탐색, 개인 기록, 운영 기능을 복구한 프로젝트입니다.

## 주요 기능

- **검색·지도 탐색** — 카테고리와 지역 필터, 자동완성, 지도 범위에 맞춘 장소 목록과 마커 묶음을 제공합니다.
- **장소 추천·상세 정보** — 여행 취향, 지역 다양성, 관광공사 당일 집중률 예측을 반영하고 조회 가능한 이용·접근성 정보를 보여줍니다.
- **여행 기록** — 장소 찜, 후기, 사진과 글을 담는 다이어리, 프로필과 활동 배지를 제공합니다.
- **관리자 운영** — 공지·제보·문의 관리와 데이터베이스 백업 상태 확인을 지원합니다.

## 기술 스택

| 영역 | 사용 기술 |
| --- | --- |
| 웹 | React 19 · Vite · React Router · Leaflet |
| 서버 | Java 17 · Spring Boot 3.5 · Gradle · Spring Security |
| 데이터 | 로컬 H2 파일 DB · JDBC · 한국관광공사 관광정보 API |
| 인증 | BCrypt · DB 세션 · HttpOnly 쿠키 · CSRF · Gmail SMTP 연동 |

## 실행 방법

**JDK 17**과 **Node.js 22.12 이상**을 준비합니다. Windows에서 저장소 루트를 연 뒤 두 터미널에서 각각 실행합니다.

| 터미널 | 명령 | 접속 주소 |
| --- | --- | --- |
| 백엔드 | `.\run-backend.cmd` | [API 상태 확인](http://127.0.0.1:8080/api/health) |
| 프런트엔드 | `.\run-frontend.cmd` | [여행지 탐색](http://127.0.0.1:5173/) |

백엔드는 로컬 H2와 기초 장소 데이터로 시작합니다. 관광공사 상세 데이터, 소셜 로그인, 가입 인증 메일을 시험하려면 [환경변수 예시](.env.example)를 루트의 `.env`로 복사하고 각 서비스 설정을 채웁니다. 계정 기능을 시연할 때는 이메일 인증 설정부터 확인하세요. [이메일 연동 안내](docs/EMAIL_AUTH.md)

## 검증과 자료

- 프런트엔드에서 `npm test`와 `npm run build`, 백엔드에서 `.\gradlew.bat test bootJar`를 실행합니다.
- 복구 범위와 남은 작업은 [복구 기록](docs/RESTORATION_STATUS.md), 추천 근거는 [추천 기준](docs/RECOMMENDATIONS.md), 운영 절차는 [백업·복구 안내](docs/OPERATIONS.md)를 참고하세요.
- 공개 저장소에는 기초 장소 자료가 포함됩니다. 운영 DB와 계정 설정은 운영 환경에서 관리합니다.

세부 환경변수, 관리자 지정 방법, 임시 공유 절차는 [기존 운영 README](https://github.com/hacho1/soomgil/blob/c1b66ab40e7e9f6414b93fe2b4c3831821afed88/README.md)에 기록되어 있습니다.
