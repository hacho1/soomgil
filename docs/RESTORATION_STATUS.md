## 데이터와 운영 주의점

- 검색은 확보한 자료와 API 1회 최대 60건의 보충 결과를 대상으로 합니다. 지도에서는 다음 페이지를 추가 조회할 수 있습니다. 전국의 모든 장소를 수집 완료했다는 의미가 아닙니다.
- 지역 미선택 시 지역 코드 없이 관광공사에 요청합니다. 5초 응답 제한, 30분 캐시, 1분 실패 대기, 프로세스당 하루 500회 제한이 있습니다. 다중 서버 운영에는 중앙 호출 제한이 필요합니다.
- 복구 사진 출처는 한국관광공사입니다. 참고 이미지에는 별도 표시합니다. 촬영 계절과 배너 문구가 항상 일치하는 수준의 시즌별 자산 편집은 추가 작업입니다.
- 숨길 평점/혼잡도를 임의 수치로 채우지 않습니다. 반려동물/무장애도 공식 상세 응답 연결 전까지 가능하다고 단정하지 않습니다.
- 주변 추천은 실제 좌표의 30km 이내 2곳, 코스는 직선거리 기반 참고 정보입니다. AI 생성이나 실제 길찾기 결과가 아닙니다.
- 기본 DB는 H2 파일입니다. 이전 MariaDB 회원/후기/다이어리 전체를 이관한 상태가 아닙니다.
- 관리자 아이디는 서버 설정으로 지정합니다. `admin.html` 주소를 알아도 일반 사용자는 관리 API에 접근할 수 없습니다.
- 비로그인 다크 모드는 브라우저에, 로그인 사용자의 다크 모드는 DB에도 저장됩니다. 언어는 현재 한국어만 지원합니다.

## 검증과 백업

- 백엔드 테스트 13개: 인증·CSRF·소유권·세션·DB 저장·보상 중복·알림 읽음·관리자 CRUD·제보 상태·관광공사 캐시/실패·지역 코드.
- 프론트엔드 프로덕션 빌드. 지도와 다이어리 지연 로딩으로 초기 번들 분리.
- 달력 단위 테스트 3개(윤년/세기 규칙/요일 위치) 통과. 다이어리 다크 모드 본문 색과 미저장 상태의 브라우저 뒤로가기 확인창을 실제 브라우저에서 확인.
- 실제 브라우저: 모바일 홈/카테고리/검색, 작은 화면의 카드 넘침과 필터 덮임, 지도 범례/요약/상세, 상세 뒤로가기/Esc, 로그인 새로고침 유지.
- test1 프로필에 테스트 이미지 업로드/회전/확대/저장. 새로고침 후 512x512 JPEG 유지 확인, 이후 원래 기본 아이콘으로 복원.
- 관광공사 실제 검색 연결 성공. 키는 서버 전용 `.env`에 보관하고 Git 제외.
- 수정 전 DB: `backup/pre-restoration-20260911/soomgil.mv.db`로 서버 중지 후 백업, 원본과 SHA-256 일치 확인.
- 점검 시 D드라이브는 연결되어 있지 않았습니다. Git 원격 저장소도 없으므로 외장하드/GitHub 백업 완료로 간주하면 안 됩니다.
- `scripts/backup-local.ps1`은 현재 미커밋 소스를 포함한 ZIP과 커밋된 이력의 Git bundle을 각각 생성합니다. `.env`와 DB는 제외합니다. 외장하드를 다시 연결한 후 `-Destination 'D:\숨길\백업'`으로 별도 사본을 만들 수 있습니다.

## 남은 복구 및 출시 전 과제

1. MariaDB 실제 접속/이관/복구 훈련, 운영용 마이그레이션, 이미지 파일 저장소 분리. 기존 사용자 데이터는 검토 후 별도 이관.
2. 이메일·문자 본인 인증, 안전한 아이디 찾기/비밀번호 재설정, 인증 시도 제한과 봇 방어. 테스트 계정과 노출된 비밀키 정리.
3. Gemini 등 AI 서버 연동과 예산/응답 검증. 공식 상세 API 기반 반려동물·무장애·두루누비·고캠핑·혼잡도 자료 연결.
4. 저장한 여행 코스, 정교한 개인화 추천, 네이버 자동완성 자료 확장과 수집 관리 복구.
5. 다이어리 자유 그림·배지 스티커 이동/본문 배치, 여러 장 사진, 게시판 수준의 전체 리치 텍스트 편집 도구.
6. 팔로우 사용자별 공개 프로필/공개 찜목록 정책과 화면 보강. 현재 관계 목록과 지도 팔로잉 추천 제공.
7. 금칙어 우회/오탐 대응, 신고·운영 정책. 현재 단어 목록만으로 모든 유해 표현을 차단하지 못함.
8. 실제 Android/iOS 키보드·터치·접근성/성능·부하·장시간 운영 테스트, HTTPS 도메인 및 OAuth 출처 설정.
9. GitHub 원격 연결과 정기 백업. C드라이브 내부 사본만으로는 디스크 고장에 대비할 수 없음.
