# 2026-09-16 배포 준비 점검

## 판단

숨길 전용 Windows 지리산 서버에 **제한된 베타를 배포할 자료는 준비할 수 있는 상태**입니다. 운영 설정과 실제 학교 서버 검증이 남아 있어, 불특정 다수 공개 승인 또는 무장애 보장은 아닙니다. 이번 작업은 학교 서버에 접속하거나 서비스를 설치하지 않았습니다.

인수인계: [JIRI_HANDOFF.md](JIRI_HANDOFF.md). 외장하드는 운반용이며 서버 내부 고정 디스크에서 실행합니다.

## 발견하고 수정한 항목

1. 백엔드 라이브러리가 오래된 패치 버전이었습니다. Spring Boot 3.5.0 → 3.5.16, Tomcat 10.1.60, Jackson BOM 2.21.6, Log4j 2.25.5, MariaDB 드라이버 3.5.10으로 패치했습니다. 주요 버전 업그레이드는 하지 않았고 실제 DB 엔진 H2 2.3.232는 유지했습니다.
2. `SOOMGIL_DEMO_USERS=false`는 기존 테스트 계정을 삭제하거나 막지 않았습니다. production/sharing에서는 `test1`, `test01`, `demo`의 신규 로그인·가입과 복원 세션 사용을 차단하고, 운영 관리자 이름으로도 지정하지 못하게 했습니다. 로컬 개발 모드는 유지합니다.
3. 운영·백업 API가 이전 세션에 남은 관리자 역할만으로 호출될 여지가 있었습니다. 현재 서버 설정의 관리자 아이디와 일치하는지 매번 재검사합니다.
4. 서비스 실행 설정에 새 PC의 `JAVA_HOME`과 도메인 설정 누락 가능성이 있었습니다. 배포 묶음의 Java 경로와 지리산 전용 도메인을 서비스 XML에 명시하고 필요한 실행 도구를 동봉합니다.
5. 배포 점검 도구가 연결 불가 상황에서도 모든 요청을 반복해 오래 기다렸습니다. 첫 상태 확인부터 HTTP 응답이 없으면 나머지 검사를 수행하지 않았음을 명시하고 중단합니다.
6. 운영 문서의 GitHub 미등록 표기를 실제 비공개 저장소 상태에 맞췄습니다. 직전 카테고리 아이콘과 이번 점검 수정은 최신 소스 묶음에 포함되지만, 이번 작업에서 GitHub 푸시는 실행하지 않았습니다.

## 공개 전에 반드시 할 일

1. `private/config.env` 원본에는 운영 관리자 아이디가 비어 있습니다. 먼저 존재하는 개인 계정을 선택하고 운영 관리자 아이디를 지정해야 합니다. 지정 없이 production을 실행하면 시작을 거부합니다.
2. 운영 출처를 `https://jiri.hknu.ac.kr`로 지정하고 네이버 로컬 콜백을 학교 주소로 바꿉니다. 제공자 콘솔 등록/검수와 실제 로그인을 별도로 확인합니다. 현재 공유 모드의 Google/Naver 비활성화는 의도된 설정입니다.
3. 채팅에 노출된 API 비밀키와 메일 앱 비밀번호를 교체합니다. 복사한 설정은 자동으로 새 비밀키가 되는 것이 아닙니다.
4. DB 이전 직전 최종 백업 시각을 확인합니다. 동봉 백업 이후의 가입·작성은 별도 최신 백업 없이는 이전되지 않습니다. 복원한 사본의 기존 세션과 이메일 인증 요청을 폐기하고 원본 백업은 보존합니다.
5. 실제 Windows 버전·.NET Framework·관리 권한·80/443·DNS·TLS를 확인하고, 최소 권한 서비스 계정으로 설치합니다. DB와 비밀 설정은 웹 루트 밖에 둡니다.
6. 실제 휴대폰의 가입·메일·소셜 로그인·검색·찜·다이어리 저장·재로그인, 재부팅 자동 시작, 최신 DB 백업과 다른 디스크 복원을 확인합니다.
