# 지도 탐색과 혼잡도 연결

> 이후 전국 DB 동기화와 서버 페이지 조회를 추가했다. 현재 동작과 한도는 [CATALOG_SYNC.md](CATALOG_SYNC.md)를 따른다. 아래 1,358건/60건 외부 보충/전체 배열 응답 설명은 전환 전 점검 기록이다.

최종 반영일: 2026-09-14. 평점 값과 산정 방식은 변경하지 않았다.

최종 실행 확인: 2026-09-14. 순포해변은 당일 예측 21.15 / 한적함으로 갱신됐고, 목록에 전날 예측 날짜가 남지 않는 것을 확인했다.

같은 날 추가 수정: 복구 전 대화 기록에서 원래 40/70 계산식을 확인해 복원했다. 검색/지도 카드의 자동 조회와 상태 구분도 추가했다. 근거 및 최신 검증은 `CROWD_CALCULATION.md`를 따른다.

## 화면과 장소 범위

- 기존의 86곳 표시는 당시 확보한 장소 수였으며, 관광공사 전체 장소 수나 서비스의 최대 개수가 아니다.
- 기본 범위는 '내 주변'이며, 위치를 선택하기 전에는 전국 지도에 장소 마커를 올리지 않는다. 위치 권한은 '내 위치로 찾기'를 누를 때만 요청한다. 위치 거부/실패 시 지역 선택과 지도 중심 탐색을 이용할 수 있다.
- 내 주변 반경은 기본 3km, 선택값은 1/3/5/10km다. 지역 선택은 해당 지역의 대표 지점을 기준으로 하며, '여기서 찾기'는 현재 지도 중심 기준이다. 기기 위치와 선택 위치를 문구로 구분한다.
- 실제 Leaflet 거리로 반경 안의 장소만 추리고, 목록과 지도 마커는 같은 페이지의 최대 6곳만 표시한다. 근접한 마커는 숫자로 묶인다. 목록 페이지를 넘기면 마커도 교체된다.
- 자연·산책 우선 또는 기준 위치에서 가까운순으로 정렬한다. 지도 이동/미리보기 닫기로 목록 페이지를 임의로 초기화하지 않는다.
- 자연·산책 우선은 장소명과 분류 기반의 테마 정렬이다. 실제 방문객이 적거나 덜 알려졌다는 보증은 아니다.
- 찜/팔로잉은 각 사용자에게 허용된 목록만 표시하고 주변 반경으로 제한하지 않는다. 비로그인 사용자는 강제 이동 없이 로그인/회원가입을 선택한다. 두 목록이 비어 있어도 전국 장소로 대체하지 않는다.
- 관광공사 장소는 60건 단위로 추가 조회하고 DB에 저장한다. '반경 내 확보한 장소', '현재 지도 6곳', '공급자 조회 건수'를 구분한다. 전송 좌표는 소수 3자리로 반올림하고, 반올림 경계 누락 방지를 위해 공급자 반경에 100m를 더한다. 화면에서는 선택한 정확한 반경을 다시 적용한다. 도 경계를 넘는 주변 장소도 포함한다.
- 비동기 위치 조회/관광공사 조회 도중 다른 지역·분류·범위를 선택하거나 화면을 나가면 이전 응답을 무시한다. 위치는 브라우저 저장소나 사용자 프로필에 저장하지 않는다.
- 초기 지역별 보충과 검증 후 공개 장소 1,241건, 유효 지도 좌표 1,236건을 확인했다. 이후 조회에 따라 늘어난다.
- 2026-09-14 이번 점검 후 공개 장소는 1,358건, 그중 `tour-api:*`는 1,333건이었다. 서울 지도에서 불러온 서울도서관(id 1420)이 키워드 검색에서도 조회됐다.
- 같은 날 공식 전국 목록의 totalCount는 49,722였다. 관광지뿐 아니라 음식점·시설·행사 등도 포함된 레코드 수이며, 모두 고유한 숨은 장소라는 의미는 아니다. 전체를 내려받지는 않았다. [한국관광공사 국문 관광정보](https://www.data.go.kr/data/15101578/openapi.do)
- 검색 결과에 있던 최대 5페이지 제한도 제거했다. 한 화면의 페이지 번호는 최대 5개만 보여주되 이후 페이지로 이동할 수 있다. 검색 키워드 자체의 외부 보충은 여전히 첫 60건이다.

## API와 지역 코드

- `GET /api/places/discover`: region, category, page, mapX, mapY, radius. 응답은 items, state, total, page, pageSize, hasMore, storedTotal이다.
- `KorService2/areaBasedList2`와 `locationBasedList2`를 사용한다. 사진이 없는 장소도 조회하고, 이미지가 없는 카드는 참고 이미지로 표시한다.
- 폐기 예정인 areaCode 대신 lDongRegnCd를 사용한다. 2026-09-13 공급자의 ldongCode2 응답 기준으로 전남·광주는 12, 세종은 36110이다. 기존 광주·전남 이름은 통합 표시명으로 매핑하고 자동완성에도 별칭을 추가했다.
- places에 legal_area_code와 legal_district_code를 추가했다. 공급자의 2자리 시도+3자리 시군구 코드만 혼잡도용 5자리 코드로 조합한다.
- 세종의 목록 응답은 두 지역 코드 필드에 모두 36110을 반환했다. 혼잡도 API용 코드로 임의 변환하지 않고 해당 예측 연결은 보류한다.
- 장소 ID는 유지하고 같은 공급자 contentid는 갱신한다. 관리자 승인 여부와 사용자 제보는 공급자 목록으로 덮어쓰지 않는다.
- 키는 서버 환경 설정만 사용한다. 5초 제한, 30분 페이지 캐시, 1분 실패 대기, 프로세스당 하루 500회 제한을 적용한다. 실패 로그에는 예외 종류만 남기고 키가 들어간 URL이나 예외 본문은 남기지 않는다.

## 혼잡도 산정

관광공사 관광지 집중률 예측 서비스를 연결했다. 과거 이동통신 기반 자료로 예측한 상대적인 집중률이며 실시간 방문자 수나 시설 수용률이 아니다. [관광지 집중률 예측 정보](https://www.data.go.kr/data/15128555/openapi.do)

- `TatsCnctrRateService/tatsCnctrRatedList`: 장소 이름, 시도, 시군구, 한국 날짜 기준 오늘이 모두 일치한 응답만 사용한다.
- 복원한 숨길 자체 표시 기준: 0 이상 40 미만은 한적함, 40 이상 70 미만은 보통, 70 이상 100 이하는 붐빔이다. 관광공사가 제공한 공식 등급 구간으로 주장하지 않는다.
- 999, 범위 밖, 잘못된 날짜, 다른 장소나 지역의 값은 제외한다. 시군구 전체 방문자 수를 개별 장소 혼잡도로 대입하지 않는다.
- 순포해변의 2026-09-13 예측 값 39.4를 받아 캐시 유지 여부를 확인했다. 당시 임시 구간은 보통이었으나 복원한 40/70 기준으로는 한적함이다.
- `GET /api/places/{id}/crowd-info`와 상세 조회가 예측을 보충한다. 목록 API 자체는 캐시만 적용하며 검색/지도/홈/찜/최근 본 장소/상세의 주변 장소 카드에서 필요한 장소만 순차 조회한다. 찜/최근 목록은 6곳부터 더 보기로 늘린다.
- 예측값이 있으면 crowdBasis=forecast, crowdSource=tourapi-concentration, crowdDate, crowdValue를 전달한다. crowdVerified=false를 유지해 실시간 측정으로 해석되지 않도록 한다.
- 당일 예측이 없으면 기존 복구 자료가 있는 5곳만 보관 값으로 대체한다. 둘 다 없으면 '혼잡도 미제공'을 표시한다. 조회 전/조회 중/연결 확인/조회 지연도 구분하며, 지연·연결 실패는 다시 확인할 수 있다. 미제공 장소에 임의 등급을 만들지 않는다.
- 카드의 '이전 자료' 문구를 제거했다. 상세에만 예측 기준일 또는 수집일 미확인 안내를 한 줄 표시한다. 평점은 그대로다.
- tour_crowd_cache에 공개 예측과 조회 시간을 저장한다. 정상 응답 12시간, 자료 없음 30분 캐시, 당일 날짜 검증, 3초 응답 제한, 오류 시 1분 대기, 프로세스당 하루 200회 제한을 적용한다.

## 검증과 보관

- 기존 백엔드 테스트 59개 통과 상태를 Gradle 캐시로 확인했고, 이번 변경의 프론트 테스트 37개 통과와 Vite 프로덕션 빌드 성공을 확인했다. 이번에는 백엔드 소스/스키마를 변경하지 않았다.
- 잘못된 탐색 범위, 전국/지역/주변 요청, 페이지별 total/hasMore, 캐시, 혼잡도 구간과 잘못된 매칭, 기존 평점 유지 테스트를 포함한다.
- 320px, 390px 모바일 화면과 1280px 데스크톱에서 지도 배치를 점검했다. 모바일 가로 넘침 없음, 목록 6개 제한을 확인했다.
- 비로그인 다이어리 상단에 복귀 버튼과 제목을 추가했다. 하단 메뉴로 진입한 화면의 경로를 전달해 기존 화면으로 돌아가고 브라우저 스크롤 복원을 유지한다. 마이페이지 → 다이어리 → 마이페이지 복귀를 확인했다.
- 실제 사용자의 위치 권한을 대신 승인하지 않았다. 기기 위치 허용 흐름은 사용자 기기에서 최종 확인이 필요하다. 반경 계산/범위별 데이터 분리 테스트와 위치 권한 없는 지역 선택, 목록 페이지 전환, 모달 Escape 닫기, 하단 여백을 검증했다.
- 세종 지역 조회, 지도 중심 주변 조회의 1~2페이지, 지도 요약에서 상세 모달 1개로 전환, Escape 닫기, 순포해변의 예측 안내, 검색 6페이지 접근을 확인했다.
- 초기 API 조회에서 일시적인 실패가 있었고 재조회에서 정상 응답했다. 외부 서비스의 무중단 동작을 보장하지 않으며 실패해도 저장된 장소는 탐색할 수 있다.
- 코드 백업은 기존 `scripts/backup-local.ps1`을 사용한다. 현재 작업의 보관 폴더는 C의 `backup/map-discovery-20260913-170846`, D의 `숨길/backup/map-discovery-20260913`이다. 소스 ZIP에는 미커밋 코드가 포함되고 Git bundle에는 커밋 기록만 포함된다. DB는 서버를 중지한 상태에서 별도 복사하고 해시를 비교한다.
- 외장하드의 독립적인 수정은 이전 소스 ZIP과 비교해 보호한다. 실행 중인 외장하드 DB를 덮어쓰지 않는다. .env와 DB는 소스 ZIP에서 제외한다. 이 백업은 GitHub 업로드가 아니다.

## 남은 운영 범위

- 전국 자료 전체 수집이나 모든 장소의 혼잡도 제공을 완료한 상태가 아니다. 예측 서비스에 등록되고 정확히 매칭되는 장소만 산정한다.
- 현재 `/api/places`는 확보한 공개 목록 전체를 반환한다. 수만 건을 운영하려면 서버 페이지 조회, 공간 인덱스와 영역별 조회를 추가해야 한다.
- API 호출 한도와 일부 캐시는 프로세스 단위다. 다중 서버 및 재시작까지 포함하는 중앙 사용량 제어는 별도 작업이다.
- 혼잡도 구간은 검증된 실측 등급이 아니라 자체 표시 정책이다. 향후 현장 피드백으로 구간을 검증하고 관측 자료와 예측 자료를 계속 구분해야 한다.
