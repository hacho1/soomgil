# 기존 혼잡도 자료 복구

2026-09-13 반영. 평점 값과 평점 계산은 변경하지 않았다.

같은 날 후속 변경: 관광공사 당일 집중률 예측이 있으면 이를 우선하고, 없을 때 아래 보관 자료를 사용한다. 카드의 '이전 자료' 표시는 제거했으며 상세에만 짧은 기준 안내를 표시한다. 현재 산정 구간과 API는 `MAP_DISCOVERY.md`를 따른다. 아래 표는 복구 당시 원본 값의 기록이다.

## 원인과 복구 범위

기존 `scripts/restore_catalog.py`는 MariaDB 백업의 공개 장소 이름, 주소, 사진, 좌표만 복원하고 `concentration`과 `level`을 제외했다. 원본 `backup/soomgil_db_latest.sql`에서 유효 범위의 값과 원래 등급이 함께 남은 5곳을 별도 공개 JSON으로 복구했다.

| 장소 | 원본 concentration | 원본 level |
| --- | --- | --- |
| 순포해변 | 17.93 | 한적함 |
| 뒷뜨루관광농원 | 11.94 | 한적함 |
| 소돌해수욕장 | 28.01 | 한적함 |
| 오대산 소금강계곡 | 16.40 | 한적함 |
| 묵호등대 | 23.27 | 한적함 |

- 백업 작성일은 `2026-09-09T19:50:04`이며, 실제 수집일이 아니다.
- 수집 기간, 산정 공식, 혼잡도 측정 원출처는 백업만으로 확인할 수 없다. 장소의 `tour-api` 출처를 혼잡도 측정 기관으로 간주하지 않는다. 뒷뜨루관광농원의 기존 source는 null이다.
- 비어 있는 값, 999, 0~100 범위 밖, 알 수 없는 등급, test/submission/fallback 자료는 사용하지 않는다. 새로운 임계값으로 등급을 재계산하지 않았다.
- 복구한 수치를 백분율이나 방문자 수로 표시하지 않는다. 값의 단위도 원본에서 검증되지 않았다.
- 다른 장소나 지역의 혼잡도로 대체하거나 장소 인기도로 추정하지 않는다.

## 코드와 API

- 공개 복구 파일: `backend/src/main/resources/data/recovered-crowd.json`
- 백업에서 다시 추출: `python scripts/restore_catalog.py --crowd-only`
- `ArchivedCrowd`가 시작 시 JSON을 읽는다. 기존 장소 ID는 재사용하지 않고 이름과 좌표를 함께 비교한다. 사용자 제보·임시 장소에는 연결하지 않는다.
- 기존 H2 places 값은 덮어쓰지 않는다. API 응답에서 검증한 보관 자료를 연결하므로 서버 재시작과 관광공사 장소 정보 갱신 이후에도 유지된다.
- `crowdAvailable=true`, `crowdBasis=archived`, `crowdSource=legacy-db`, `crowdValue`, `crowdBackupAt`, `crowdCollectedAt=null`로 전달한다. `crowdVerified=false`를 유지해 최신 검증 자료인 것처럼 표시하지 않는다.
- 자료가 없는 장소는 `crowdAvailable=false`, `crowdBasis=unknown`, 수치 null이다. 기존 seed의 추측 값이나 999로 '한적함'/'붐빔'을 반환하지 않는다.
- 검색 카드, 지도 요약, 상세화면은 같은 공통 혼잡도 표시를 사용한다. 미확보 장소에는 '혼잡도 자료 없음'을 표시한다. 보관 자료의 수집일 미확인 안내는 상세에서만 짧게 표시한다.
- 검색 혼잡도 필터도 같은 자료 여부 기준을 사용한다.

## 검증

- 백엔드: 5곳의 원본 값/등급, 장소·좌표 일치, 출처 제한, 비정상 값 제외, 목록/상세 API 일관성, 기존 테스트 전체 통과.
- 프론트: 보관 자료 필터링, 자료 없음, 무효 값, 안내 문구 테스트와 프로덕션 빌드 통과.
- 실행 중 API에서 5곳 복구 확인. 순포해변 상세 320px, 검색 결과 390px에서 혼잡도 글씨/카드 가로 넘침 없음 확인.

전국 혼잡도를 복구 완료한 상태는 아니다. 다른 장소는 별도의 수집 원본이나 출처·기간이 있는 새 혼잡도 자료가 필요하다.
