# 장소 상세정보 연결

확인일: 2026-09-13

2026-09-15 후속 변경: `PLACE_DATA_QUALITY.md` 참고. 산정 자료가 없는 평점은 표시하지 않고, 공식 여행 코스는 코스 소개/소요시간/길이를 안내한다. 코스 전체를 한 지점의 혼잡도나 반려동물/접근성 정보로 표현하지 않는다.

후속 연결: 관광공사 집중률 예측을 별도 `CrowdForecast`에서 받아 자체 구간으로 혼잡도를 표시한다. 실시간 측정이 아니며, 검증 기준과 보관 자료 대체 정책은 `MAP_DISCOVERY.md`를 따른다. 아래 상세 API 자체가 평점이나 혼잡도를 제공하는 것은 아니다.

## 원인과 변경

기존 복구본은 검색 목록만 조회했고, 상세정보 API 호출이 없었다. 기존 DB의 검증되지 않은 반려동물·접근성·평점·혼잡도 자료는 `placeMap()`에서 확인 필요로 처리했다. 이 값의 덮어쓰기를 단순히 제거하면 오래된 추정 정보가 사실처럼 표시될 수 있으므로, 검증된 공식 응답을 별도 경로로 연결했다.

- `GET /api/places/{id}/visit-info` 추가. 공개 승인된 장소만 조회할 수 있다.
- 기존 장소 상세/후기/공유는 먼저 표시하고, 공식 안내는 별도로 불러온다.
- `KorService2/detailCommon2`: 장소 소개, 홈페이지, 관광정보 수정일.
- `KorService2/detailIntro2`: 유형별 이용시간, 휴무일, 주차, 문의처, 요금, 메뉴, 예약, 입퇴실 안내.
- `KorService2/detailPetTour2`: 동반 구역, 대상, 준비물, 조건 및 주의사항.
- `KorWithService2/detailWithTour2`: 접근로, 장애인 주차, 화장실 등 시설별 접근성 정보.
- 지도 요약과 상세 화면이 같은 공식 안내를 사용한다. 동반 제한 조건과 시설의 '없음'도 원문 의미대로 유지한다.
- 정보 미등록, 장소 매칭 실패, 일시적 연결 실패, 이전 자료 사용을 구분한다.
- 평점/실시간 혼잡도는 위 API가 제공하는 값이 아니다. 평점 산정 자료가 없으면 확인 불가로 표시하고, 혼잡도는 후속 예측 또는 복구 자료가 있을 때만 표시한다.

## 데이터와 보호

- 키는 서버의 `SOOMGIL_TOUR_API_KEY`만 사용하며 프론트, 응답, 로그에 넣지 않는다.
- 검색으로 저장된 `source=tour-api:<contentid>`를 우선 사용한다.
- ID를 잃은 복구 자료는 정확한 이름과 동일 주소 또는 150m 이내 좌표를 확인한다. 후보가 여러 개면 연결하지 않는다. 사용자 제보는 이름만으로 자동 연결하지 않는다.
- 각 상세 응답의 `contentid`가 요청 ID와 일치해야 사용한다.
- 신규 `tour_detail_cache` 테이블에 공개 API 응답, 조회 시각, 재시도 시각, 상태를 저장한다. 기존 회원 및 장소 데이터를 덮어쓰지 않는다.
- 성공/빈 응답은 24시간 캐시. 실패는 1분 대기. 성공했던 자료가 7일 이내라면 이전 조회일과 함께 제공하고, 그보다 오래되면 제공하지 않는다.
- 프로세스당 동시 요청 6개, 같은 요청 합치기, 요청당 기본 3초 제한, 상세 요청 하루 기본 400회 제한. 기존 검색 한도와 별도로 계산하므로 실제 공급자 전체 할당량에 맞춰 조절한다. 다중 서버/재시작을 포함한 중앙 사용량 제어는 별도 운영 과제다.
- `SOOMGIL_TOUR_DETAIL_TIMEOUT_MS`, `SOOMGIL_TOUR_DETAIL_DAILY_LIMIT`로 조절할 수 있다.
- jsoup으로 제공 HTML을 텍스트로 변환한다. 스크립트/스타일/iframe은 제거하고, 홈페이지 링크는 HTTP(S)만 허용한다. HTML을 프론트에서 실행하지 않는다.

## 검증

- 백엔드: 기존 포함 47개 테스트 통과. 공식 응답 매핑, ID 불일치 거절, HTML 처리, 부분 실패, 캐시 재사용, 재시도 대기, 오래된 자료 제외, 시간 제한, 복구 자료 매칭, 비공개 장소 보호 포함.
- 프론트: 21개 테스트 및 프로덕션 빌드 통과.
- 실제 API: 강화 동막해변(contentid 127291), 순포해변(contentid 2775497) 조회 성공. 순포해변은 복구 자료에서 이름/위치 확인 후 연결했다.
- 운영시간/반려동물/접근성은 제공기관 조회 시점 자료다. 이용자의 동선 전체에 대한 접근성이나 현재 운영 상태를 보장하지 않는다.

## 범위 밖

Gemini 추천, 방문자 통계 기반 혼잡도 산정, 고캠핑·두루누비 고유 코스/예약정보는 이번 수정에 포함하지 않았다. 관광공사 상세 정보와 실제 코스 경로/실시간 혼잡도는 서로 다른 데이터다.
